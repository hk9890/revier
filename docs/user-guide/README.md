# revier user guide

revier shows what every coding agent in every project is doing, and takes you
to the one that needs you in one keystroke.

You run Claude Code in five projects. One waits for a permission. revier shows
you which one, and one key takes you to its tab. Each project's editor, pages
and tools are one key away too, and the same key takes you back.

Start with [Getting started](getting-started.md). Read [Concepts](concepts.md)
once. Read the other pages when you need them.
